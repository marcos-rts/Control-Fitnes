
# Crucifixo no Voador (Máquina) -> Peck Deck

![[Peck-Deck.gif]]

1. Selecione a carga apropriada e ajuste a altura do assento. As alças da máquina devem estar na altura do peito quando você se sentar.

2. Sente-se, traga os ombros para trás e alcance as laterais para segurar as alças.

3. Contraia o abdômen e respire.

4. Aperte o peito e traga os braços para dentro, tocando levemente os nós dos dedos na frente do peito.

5. Traga os braços para os lados, sentindo os músculos do peito se alongarem. Expire.
